Kết nối dữ liệu MT5 (Exness) vào web

EA nhỏ chạy trong MT5 gửi giá và nến M5/M15/H1/H4 lên Firebase (miễn phí của Google). Trang tín hiệu đọc từ đó nên giá, nến, Entry/SL/TP khớp đúng với MT5. EA này không đặt lệnh.

Tải EA MT5_Bridge_Firebase.mq5← Về trang tín hiệu

1Tạo kho Firebase (làm 1 lần, ~3 phút)

  1. Vào console.firebase.google.com, đăng nhập Google.
  2. Create a project → đặt tên (VD letuan-mt5) → tắt Google Analytics → Create.
  3. Menu trái: Build → Realtime Database → Create Database → chọn vị trí Singapore (asia-southeast1) → Start in locked mode → Enable.
  4. Mở tab Rules, xoá hết rồi dán đoạn dưới → Publish: 
    {
  "rules": {
    ".read": false,
    ".write": false,
    "mt5": { ".read": true, ".write": true },
    "bot": { ".read": true, ".write": true },
    "botev": { ".read": true, ".write": true }
  }
}
  5. Mở tab Data, sao chép địa chỉ ở trên cùng, dạng https://letuan-mt5-default-rtdb.asia-southeast1.firebasedatabase.app.

2Cho phép MT5 gửi dữ liệu

  1. Trong MT5: Tools → Options → Expert Advisors.
  2. Tích Allow WebRequest for listed URL, bấm thêm dòng mới và dán địa chỉ Firebase ở bước 1 → OK.

3Cài EA

  1. MT5: File → Open Data Folder → MQL5 → Experts, chép file MT5_Bridge_Firebase.mq5 vào đây.
  2. Mở MetaEditor (F4), mở file đó, bấm Compile (F7) – phải báo 0 errors.
  3. Quay lại MT5, mở một chart riêng (VD XAUUSDm M5 – không dùng chart đang chạy bot giao dịch), kéo EA MT5_Bridge_Firebase từ Navigator vào chart.
  4. Tab Inputs: dán địa chỉ Firebase vào InpDbUrl; kiểm tra InpSymbols đúng tên mã trong Market Watch (Exness thường là XAUUSDm,BTCUSDm) → OK.
  5. Góc trái chart hiện "Gửi thành công: …" là chạy đúng. Nếu báo "Chưa cho phép WebRequest" → làm lại bước 2.

4Nối web với MT5

  1. Mở trang tín hiệu, ô Nguồn MT5 (Exness): dán địa chỉ Firebase, kiểm tra tên mã → Lưu & kết nối MT5.
  2. Nhãn nguồn chuyển màu xanh "MT5 Exness · XAUUSDm" là đang dùng dữ liệu MT5.
  3. Trên điện thoại cũng nhập địa chỉ này 1 lần (mỗi trình duyệt lưu riêng).

!Lưu ý

Web chỉ có dữ liệu MT5 khi máy tính đang bật và MT5 đang chạy EA. Khi MT5 tắt (hoặc cuối tuần sàn vàng đóng), trang tự quay về nguồn Binance và hiện nhãn vàng "MT5 chưa kết nối". Muốn chạy 24/7 thì dùng VPS cho MT5.

Không chia sẻ địa chỉ Firebase công khai: kho chỉ chứa giá thị trường, nhưng ai có địa chỉ đều ghi đè được. Gói miễn phí của Firebase (1 GB lưu trữ, 10 GB tải/tháng) dư dùng cho việc này.
